# Luca Siletti — portfolio

Single-page portfolio for photographer and filmmaker Luca Siletti. One HTML file, no build step.

- `index.html` — the whole site (Three.js + GSAP + Lenis, loaded from CDNs).
- `img/` — the photos as WebP in three widths (900 / 1200 / 2000), generated by the `photos` workflow from the originals on lucasiletti.com.
- `tools/build-images.mjs` — the generator. Run `npm --prefix tools install && node tools/build-images.mjs` to rebuild locally.

Hosted with GitHub Pages from the `main` branch.
